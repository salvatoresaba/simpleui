# Hermes VS Code Extension — Install

## Quick install

```bash
# From this folder
npm install
npm run compile
npm install -g vsce
vsce package
# Then in VS Code: Extensions → ... → Install from VSIX → pick hermes-vscode-0.1.0.vsix
```

## Manual install (no build)
Copy this folder to:
```
~/.vscode/extensions/hermes-vscode-0.1.0/
```
Then restart VS Code.
