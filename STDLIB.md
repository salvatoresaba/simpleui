# SimpleUI Standard Library

The standard library reference lives in [`docs/STDLIB.md`](docs/STDLIB.md).

Current status: HTTP modules, safe URL variants, WebSocket connect/send/
onMessage/close, filesystem and exec bridge calls, JSON and the core table API
are documented there. Unsupported features (HTTP headers/multipart, WebSocket
reconnect, advanced filesystem, crypto, source maps) are tracked in
[`TODO.md`](TODO.md) and must not be treated as stable APIs.
